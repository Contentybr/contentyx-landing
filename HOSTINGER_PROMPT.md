- Imagens otimizadas
- Lazy loading
- Animações suaves ao scroll

**Acessibilidade:**
- Alto contraste (texto branco em fundo escuro)

### 📝 NOTAS FINAIS

- Use scroll suave entre seções
- Adicione micro-animações ao passar o mouse nos cards
- Botões devem ter efeito hover (mudança de opacidade ou cor)
- Mantenha espaçamento consistente entre seções (100px)
- Use a logo do Contentyx (você pode fazer upload depois)
- Todos os links "#pricing" devem levar à seção de preços
- Todos os links "#how-it-works" devem levar à seção Como Funciona

**IMPORTANTE:** Este é um site de uma página (one-page). Todas as seções devem estar na mesma página, uma após a outra, sem navegação entre páginas diferentes.

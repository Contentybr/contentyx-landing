# Contentyx Landing Page

Landing page profissional e moderna para o **Contentyx** - Ferramenta de geração de conteúdo com IA para Social Medias, Agências de Marketing, Influenciadores e Prestadores de Serviço.

## 🚀 Sobre o Projeto

Esta landing page foi desenvolvida com foco em **conversão** e **experiência do usuário**, apresentando:

- ✨ Design moderno com tema dark e gradientes vibrantes
- 🎨 Paleta de cores da marca (Azul Neon → Laranja Neon)
- 📱 Totalmente responsivo (mobile-first)
- ⚡ Performance otimizada
- 🎯 10 seções estratégicas focadas em conversão

## 🛠️ Tecnologias

- **React 19** - Framework JavaScript
- **Tailwind CSS 4** - Estilização moderna
- **shadcn/ui** - Componentes UI
- **Vite** - Build tool
- **TypeScript** - Tipagem estática

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/Contentybr/contentyx-landing.git

# Entre no diretório
cd contentyx-landing

# Instale as dependências
pnpm install

# Inicie o servidor de desenvolvimento
pnpm dev
```

## 🎨 Estrutura

```
contentyx-landing/
```

## 📄 Seções da Landing Page

1. **Hero Section** - Proposta de valor e CTAs principais
2. **Problemas** - Identificação com dores do público
3. **Benefícios** - Soluções e diferenciais
4. **Como Funciona** - Processo em 4 passos
5. **Features** - Recursos detalhados
6. **Depoimentos** - Prova social
7. **Pricing** - Plano e formulário de cadastro
8. **FAQ** - Perguntas frequentes
9. **CTA Final** - Última chamada para ação
10. **Footer** - Links e informações
